## HTTP contract (B)
All routes below under /api, same origin; raw JSON records (no data wrapper). Common User fields returned as existing public User (no hash). Cards/transactions/statistics use corresponding web/src/api/types.ts fields, money strings. Error JSON {code,message}, Chinese non-sensitive messages. Status:401 AUTH_REQUIRED/LOGIN_FAILED;403 FORBIDDEN/USER_DISABLED/CSRF_INVALID;400 VALIDATION;404 NOT_FOUND;409 DUPLICATE/OPERATION_CONFLICT;422 INSUFFICIENT_BALANCE;503 DATABASE_ERROR;500 SERVER_ERROR. Unknown failures logged server-side, never return stack/SQL/password. Request body validation, malformed dates/JSON map VALIDATION.

GET /auth/csrf -> {token,headerName}; token from Spring CSRF framework, do NOT disable CSRF. HttpOnly CAMPUS_SESSION cookie SameSite=Lax, session30m. POST /auth/login {username,password} -> User; call core login, rotate HTTP session id to prevent fixation, store server-only SessionContext in session and Spring Authentication ROLE_*. Explicitly save SecurityContext with HttpSessionSecurityContextRepository. Never return underlying session token. Invalidate previous session/core token if replacing login. Rotate CSRF after login; root frontend refreshes /csrf. GET /auth/me -> live User via core validation; POST /auth/logout ->204 (core logout + invalidate session); POST /auth/password {oldPassword,newPassword}->204 preserving current core session. Core validates disabled/expired session on every protected operation. Restrict /admin/** to ADMIN in Spring AND core. GET /health returns {status:'UP'} only after SELECT1, no config. Security unauthorized/access-denied handlers return agreed JSON; CSRF missing/invalid403 codeCSRF_INVALID.

GET /card ->Card; POST /card/recharge and /card/consume body{amount:'50.00',description,operationId} ->TransactionRecord; GET /card/operations/{operationId}->record or JSON null (not404 when missing). All refer ONLY own card. GET /transactions query userId?,type?,from?,to?,page(default1),pageSize(default20,max100)->Page<TransactionRecord> (all forADMIN, self forUSER). GET /transactions/export samefilters->UTF8 BOM text/csv + attachment filename. GET /admin/users querykeyword?,enabled?,page?,pageSize? ->Page<User>. POST /admin/users CreateUserRequest->201 User. PUT /admin/users/{id} {fullName,studentNo}->User. PATCH /admin/users/{id}/enabled {enabled}->204. GET /admin/statistics from?,to?->Statistics money strings. GET /dashboard?days=7 (1..90 default7) ->DashboardOverview from Shanghai today-days+1 through today; own forUSER/all forADMIN using live core user and UoW/DashboardReader. Dashboard statistics should never reveal other user's data.

Serve SPA static web/dist in packaged server JAR. Provide forward:/index.html only for known client routes /, /login, /dashboard, /wallet, /transactions, /users, /statistics, /settings; do not forward /api or nonexistentassets. Security permit public SPA and login/csrf/health, authenticated other /api, role admin /api/admin; cookie-only session no browser-storage tokens.
